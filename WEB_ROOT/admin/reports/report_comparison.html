Wave Comparison

Instructions

This page is designed to compare the Wave FQSR/ASR student view with the PowerSchool Transportation register.

In order to calculate differences between the report values accurately you must input the number of membership days left in the term since the date that the report was completed. You must also enter the total number of membership days in the site's full year term.

Membership differences must be calculated separately from transportation and attendance differences using the compare mmembership checkbox.

The Wave Student View must be downloaded as a csv.

Once you click the load button, it will change to "Process" and you will click it again.

Use the "Make Selection" button to create a selection using the resulting student list.

Refresh the page to process another set of files

~[tlist_sql; select SUM(dcd.membershipvalue) FROM districtcalendarday dcd join districtcalendar dc on dc.id = dcd.districtcalendarid AND dc.CalendarYear = 33 and dcd.datevalue BETWEEN trunc(sysdate) AND to_date(dc.enddate) ] [/tlist_sql]

Enter the number of membership days left in the school year since the date the report was created.
